# 💻 Projeto desenvolvido durante meus estudos de Python na ETEC.

## 📌 Sobre o projeto

Programa simples que calcula o desconto de uma compra de acordo com o valor informado pelo usuário.

## 💰 Regras de desconto
Valor da compra	desconto
- A partir de R$ 300 = 15%
- R$ 200 até R$ 299,99 = 10%
- Abaixo de R$ 200 = 5%

Variáveis
Entrada e saída de dados
- if e else
- Operações matemáticas
- f-string
